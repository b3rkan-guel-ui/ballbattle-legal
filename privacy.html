2. Summary

Ball Battle Uploader is a private tool used only by the operator with the operator's own TikTok account and YouTube channel. It does not collect data from other people, has no user accounts, no analytics, no advertising and no cookies.

3. Data the app processes

  • TikTok login data of the operator: access token, refresh token and TikTok open ID, received through TikTok Login Kit with the scopes user.info.basic and video.upload. They are stored only on the operator's own computer and used only to upload drafts.
  • YouTube/Google login data of the operator: OAuth access and refresh token received through Google OAuth with the scope youtube.upload. Stored only on the operator's own computer and used only to upload the app's own videos to the operator's YouTube channel. The app does not read, store or share any other YouTube or Google data.
  • Videos: generated by the app and sent to TikTok as drafts via the Content Posting API and to YouTube via the YouTube Data API (YouTube API Services).
  • Public comments: the operator's computer reads the text of public comments under the operator's own latest video to count which countries viewers want to see next. Only the comment text and like count are stored locally, never user names or profiles. The stored text is overwritten every day.

Legal basis: Art. 6(1)(f) GDPR (legitimate interest in running a personal hobby project). Data is not sold or shared with anyone except TikTok and YouTube (Google) as needed for the upload.

4. This website

These pages are hosted on GitHub Pages (GitHub, Inc., USA). When you open them, GitHub processes technical data such as your IP address to deliver the page and keep the service secure. See the GitHub Privacy Statement. The pages load no external fonts, trackers or scripts. The light/dark switch saves your choice only in your own browser.

5. TikTok and YouTube

Processing on TikTok's side is governed by the TikTok Privacy Policy.

This app uses YouTube API Services. Processing on YouTube's side is governed by the Google Privacy Policy and the YouTube Terms of Service. Access granted to this app can be revoked at any time on the Google security settings page.

6. Retention

Tokens are kept until the operator disconnects the app or they expire. When access is revoked on the Google security settings page, the stored YouTube token stops working and is deleted from the operator's computer on the next run. The app stores no other data received from YouTube. Videos are kept locally for 14 days. Comment texts are replaced on the next daily run. Deletion requests can be sent to guelberkan@web.de and are handled within 7 days.

7. Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection (Art. 15–21 GDPR). Contact guelberkan@web.de. You may also complain to a data protection supervisory authority.
